# Perangkat audit

Phase 1 menyediakan [kontrak teknis laporan](../docs/contracts/analysis-v1.md), [template awal](template-analysis.md), [schema manifest](../docs/contracts/manifest-v1.schema.json) dan [fixture ZIP sintetis](../tests/fixtures/README.md).

Template menetapkan struktur, bukan hasil audit. Placeholder harus diganti dari pemeriksaan video yang benar-benar dilakukan; label review penuh dan metadata tidak boleh dikarang.

Prompt Gemini/ChatGPT lengkap, rubrik tempo, contoh kalibrasi, proses koreksi/ekspor dan audit tujuh video pilot dikerjakan pada Phase 2. Fixture sintetis tidak menjadi referensi aktif atau contoh kebenaran gerakan kamera.
